# Documentation

This folder contains the technical documentation and supporting diagrams for the Cardio-Edge project.

## Contents

The documentation will include:

- System architecture
- Technical approach
- Hardware architecture
- ECG processing workflow
- AI inference workflow
- Edge-AI deployment
- Testing and evaluation
- Project report

## System Overview

Cardio-Edge combines ECG acquisition, signal processing, Edge-AI inference and cellular communication into a low-cost ECG monitoring system.

The core processing is performed locally on the Raspberry Pi 3.

## Status

Project documentation is being developed alongside the prototype.
