# ECG Datasets

This folder contains information about the datasets used for development and evaluation of the Cardio-Edge ECG classification system.

## Dataset

The project uses publicly available ECG data for AI model development and validation.

### MIT-BIH Arrhythmia Database

The MIT-BIH Arrhythmia Database is identified in the project research as a dataset for ECG analysis and arrhythmia classification.

## Dataset Usage

The dataset is used for:

- ECG signal analysis
- AI model development
- ECG classification
- Model validation

## Important

The original datasets are not stored directly in this repository.

Users should obtain the datasets from their respective official sources and follow the applicable dataset licensing and usage conditions.

## Status

Dataset preparation and model development are in progress.
