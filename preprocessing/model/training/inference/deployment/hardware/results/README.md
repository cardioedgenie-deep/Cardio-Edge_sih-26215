# Results and Evaluation

This folder contains the evaluation results of the ECG classification model and system testing.

## Evaluation Metrics

The model will be evaluated using:

- Accuracy
- Sensitivity
- Specificity
- F1-score

## Purpose

The evaluation is intended to assess the performance of the ECG classification system and its suitability for Edge-AI deployment.
